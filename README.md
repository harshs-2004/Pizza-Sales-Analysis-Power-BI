# Pizza-Sales-Analysis-Power-BI
🍕 Pizza Sales Analysis Dashboard | SQL + Power BI

📊 Project Overview

The Pizza Sales Analysis Dashboard is a data analytics project developed using SQL and Power BI to analyze pizza sales performance, revenue trends, customer ordering patterns, and product popularity.

I first used SQL to query and analyze the sales data, calculate key performance indicators (KPIs), and answer important business questions. Then, I created interactive visualizations in Power BI to present the findings in an easy-to-understand dashboard.

🎯 Project Objectives

- 💰 Analyze total revenue and sales performance.
- 📅 Identify the busiest days and months for orders.
- 🍕 Determine the best-selling and worst-selling pizzas.
- 📈 Analyze sales by pizza category and size.
- 🛒 Understand customer ordering patterns.
- 💡 Generate actionable insights to support business decisions.

🛠️ Tech Stack

- 🗄️ SQL – Data querying, aggregation, and sales analysis.
- 📊 Power BI Desktop – Interactive dashboards and data visualization.
- 🧹 Power Query – Data cleaning and transformation, where required.
- 🧮 DAX – KPI measures and calculations, where required.

📂 Dataset

The dataset contains pizza sales information, including order dates, pizza names, categories, sizes, quantities, prices, and order details.

SQL queries were used to analyze the dataset and extract meaningful business insights for the Power BI dashboard.

🔍 Key Performance Indicators (KPIs)

- 💵 Total Revenue
- 🧾 Average Order Value
- 🍕 Total Pizzas Sold
- 📦 Total Orders
- 🛒 Average Pizzas Per Order

📈 Dashboard Features

📅 1. Daily and Monthly Trends

- Analyze daily order patterns.

🍕 2. Pizza Category Analysis

- Compare sales across pizza categories.

📏 3. Pizza Size Analysis

- Compare sales by pizza size.
- Identify the most popular pizza sizes.
- Analyze the percentage contribution of each size.

🏆 4. Best and Worst Sellers

- Identify top-selling pizzas by quantity and revenue.

🎛️ 5. Interactive Dashboard

🔄 Project Workflow

1. 📥 Data Collection: Obtained the pizza sales dataset.

❓ Business Problem

Understanding sales performance is essential for a pizza business to improve profitability and meet customer demand. However, raw sales data alone does not easily reveal the most popular products, peak ordering periods, or sales patterns.

This project uses SQL and Power BI to transform raw sales data into meaningful insights that can help businesses make informed, data-driven decisions.
